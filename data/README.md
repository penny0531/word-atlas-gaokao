# 高考词图词库

目前 400 个高考英语核心词，按 CEFR 由易到难排列。第二批 200 个的选词说明见 [batch-2-notes.md](batch-2-notes.md)。

- `word-atlas.json`：结构化数据。可选 `meta.gaokaoFreq` 标记考纲频段。
- `word-atlas.csv`：表格版

基于 Word Atlas contributors（词光）。代码 MIT，内容 CC BY 4.0。不是教育部、考试院或官方考纲词表。
